# Plan template - `04-plan/plan.md`

```markdown
# <Client> - website improvement plan

## Goals and KPIs
| Goal | KPI | Baseline (if known) | Target (90 days) |
e.g. more hot-water jobs -> calls + quote forms from /hot-water -> ? -> +40%
Always include: enquiry conversion rate, enquiries/month, mobile performance score, ranking for
2-3 money keywords + suburb, Google reviews count.

## Positioning and message
Positioning statement, headline formula, proof points to repeat on every page, voice rules.

## Proposed sitemap
Tree with each page's purpose and primary CTA. Mark: new / keep / merge / remove (+ 301 target).

## The 3 key pages (for design variations)
1. <page> - why it matters (traffic/money/conversion), what must change
2. ...
3. ...

## Page-by-page plan
For each page:
- Purpose and audience
- Primary CTA / secondary CTA
- Sections in order (with the job of each)
- Content and assets needed (copy, photos, reviews, video) - who supplies
- SEO: target keyword, title, H1, schema
- Findings it fixes (IDs)

## Landing pages for ads
One per money service (or per offer). One action, no main nav, proof near the form,
message match with the ad.

## SEO plan
Technical fixes, on-page, local (GBP, citations, location pages), content topics from customer
questions, redirects map for changed URLs.

## Tracking and funnel
GA4 + GTM events (form submit, tel click, booking), Google Ads/Meta conversions, call tracking,
CRM handoff, instant response (SMS/AI), review request automation.

## Roadmap
| Phase | When | What | Findings fixed | Owner |
1. Fix (week 1-2): P1 quick wins on the current site
2. Rebuild (weeks 3-8): new design, content, SEO migration
3. Grow (months 3-6): landing pages + ads, content, reviews, automations

## Open items and dependencies
```

Choosing the 3 key pages: prefer the pages with the most business weight, not the most traffic
alone. Default = Home + top money-service page + the conversion page (quote/booking/contact or a
new ads landing page). For a clinic: Home + main treatment/condition page + booking page. For
e-commerce: Home + category/collection + product page.
